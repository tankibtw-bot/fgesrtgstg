# Retro FPS

Это рабочий прототип шутера от первого лица в стиле Half-Life / CS 1.6, собранный без внешних ассетов.

Что включено:
- передвижение с прыжком и спринтом
- стрельба по лучу (hitscan)
- враги, которые преследуют и атакуют
- здоровье и патроны
- победа/поражение и рестарт
- уровень из коробок и примитивной геометрии

Запуск:
1. Открой проект в Godot 4.3.
2. Нажми F5 или Run.
3. Управление:
   - W A S D — движение
   - Shift — бег
   - Space — прыжок
   - ЛКМ — огонь
   - R — перезарядка
   - Esc — показать курсор
