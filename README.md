# ABYSS — Godot и GoldSrc

Репозиторий содержит две независимые части:

- корень репозитория — экспериментальная Godot-версия;
- `goldsrc/` — начальный каркас отдельного мода для Half-Life 1 на GoldSrc.

GoldSrc-версия пока не содержит скомпилированных карт `.bsp` или DLL. Для запуска нужны установленная Half-Life 1 и инструменты GoldSrc-маппинга/сборки. Сюжет и план первого уровня: [`goldsrc/README.md`](goldsrc/README.md), [`goldsrc/MAP_DESIGN.md`](goldsrc/MAP_DESIGN.md).
