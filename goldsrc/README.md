# ABYSS — GoldSrc / Half-Life 1 mod

Это отдельное направление проекта под Half-Life 1 (GoldSrc), а не мод для Godot. Папка `goldsrc/` содержит начальный каркас и документацию кампании.

## Важно

Здесь пока нет готовых `.bsp`-карт и скомпилированной DLL: для них нужны Half-Life SDK, инструменты сборки карт (например, JACK/данные компилятора GoldSrc) и легальная установка Half-Life 1 для тестирования. Godot-файлы в корне репозитория не превращаются автоматически в GoldSrc-мод.

Первая техническая цель — map-only вертикальный срез: использовать штатную DLL Half-Life, собрать собственную карту `abyss01.bsp` в редакторе и пройти пролог «Смена»/«Тест». После проверки карты добавлять главы, сюжетные события и собственные сущности через HLSDK.

## Установка каркаса

1. Установи Half-Life 1 и редактор карт GoldSrc.
2. Создай папку `valve/abyss/` в каталоге игры.
3. Скопируй `liblist.gam` из этой папки в `valve/abyss/liblist.gam`.
4. Помести собранные карты в `valve/abyss/maps/`.
5. Запускай мод параметром `-game abyss` только после того, как карта `abyss01.bsp` будет собрана.

На данном этапе каркас не заявляет о готовой играбельной карте. Файлы `.bsp`, модели, звук и DLL должны быть созданы/собраны отдельно.
